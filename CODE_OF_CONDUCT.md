# Contributor Covenant Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We pledge to make participation in the Shaar community a harassment-free
experience for everyone, and to act in ways that contribute to an open,
welcoming, diverse, inclusive, and healthy community.

## Our standards

Examples of behavior that contributes to a positive environment include:

- Showing empathy and kindness
- Respecting differing opinions and experiences
- Giving and accepting constructive feedback gracefully
- Taking responsibility for mistakes and learning from them
- Focusing on what benefits the community

Examples of unacceptable behavior include sexualized language or attention,
trolling, insults, personal attacks, harassment, publishing private information
without permission, and conduct that is inappropriate in a professional setting.

## Scope and enforcement

This code applies in project spaces and when someone officially represents the
project. Project maintainers will review reports promptly and fairly, respect
reporter privacy, and may remove or reject content or participation that
violates this code. Corrective action may include a private correction, a
warning, a temporary ban, or a permanent ban, based on severity and impact.

## Reporting

Report conduct concerns privately through
[GitHub Security Advisories](https://github.com/arcusis/shaar/security/advisories/new).
For non-security conduct reports, state that the report concerns the Code of
Conduct. Do not publish private details in a public issue.

This code is adapted from the Contributor Covenant, version 2.1. See the
[official text](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
and [FAQ](https://www.contributor-covenant.org/faq).
