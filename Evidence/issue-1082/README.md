# Components panel offscreen evidence

`before-components-off-*.png` shows Shaar DevTools on a normal website. The
Components section stays off and offers a one-session enable control.

`after-components-react-*.png`, `after-components-vue-*.png`, and
`after-components-angular-*.png` show the same panel after a loopback fixture
exposes that framework's component tree. The selected Counter row lists its
props and state.

All images were rendered offscreen. No window was ordered on screen and the
key window was unchanged.
