# Native keyboard commands

Command-N creates a new engine-backed window sharing Space/profile/pin definitions, with no copied ordinary tabs. Shift-Command-W closes the focused window. Command-T / Command-L opens the launcher. Command-S toggles the sidebar. Control-Option-[ / ] switches spaces. Arrow keys select launcher results, Return executes, and Escape dismisses. Opening or dismissing the launcher creates no tab. Its opaque adaptive surface stays centered within the page area, including with the sidebar hidden. Rows show existing site icons where available, action labels and Profile context; no support/contact row is added.

Command-Comma opens the reusable native Settings window. When Settings owns focus, Command-W and Shift-Command-W close Settings; page commands remain disabled. Settings profile selection changes only the preference target, never the active browser account.

With an empty query the launcher suggests, in order: Open Tabs (unpinned tabs in this Space), Favorites & Pinned, Recently Closed (this Space) and Most Visited (profile history by visit count, skipping pages already open). Filter chips Tabs, History, Bookmarks and Actions narrow results to one kind; Tab / Shift-Tab cycle through the chips and no filter, and selecting the active chip clears it. Actions are the app's menu commands (New space, Settings, Split View…) with their menu shortcuts, minus the launcher, window-chrome and repeat commands; choosing one closes the launcher, then runs the command through the native host. The UI-only shell has no host, so it lists no Actions. Rows show the site icon, title and grey domain; only the selected row shows its action hint. Up/Down selection spans sections.

Opening and closing use a ~180 ms spring scale-and-fade anchored on the panel, the results height animates as rows change, and one selection highlight slides between rows. With Reduce Motion none of these animate. `--render-preview <png> --command [--command-query <text>] [--command-filter tabs|history|bookmarks|actions]` renders the launcher with sample tabs, history, bookmarks and Actions.

A typed query with no chip returns at most ten results: ranked hits, then up to three matching Actions (word-prefix match), reserving the final slot for Open when input can navigate. Candidate traversal stops when that prefix is full; selected-Space priority, query matching and profile-scoped bookmark/history behavior remain unchanged. Space sorting and the current Space's ordered-tab array still occur before traversal; this does not establish constant-time search or a measured latency guarantee.
