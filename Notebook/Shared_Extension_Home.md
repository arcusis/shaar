# Shared extension home (#287)

The extensions module (`SHAAR_MODULE_EXTENSIONS = 1300`) should treat an approved Web Store install as one browser-wide *intent*. A browser-owned catalog records the extension ID and source. Each regular Chromium profile still gets its own installed instance. Reconcile the catalog when a profile opens, and retry failed profiles without repeating consent. An install reports each profile's outcome; partial success is never reported as full success. Uninstall from the shared home removes the intent and its instances, while the profile switch only changes that profile's enable state. Spaces inherit the profile's state. Private sessions do not own installs and require their existing explicit extension access grant.

Keep package identity, updates, permissions, and install policy in Chromium's extension service. Do not share an extension directory, `Profile`, cookies, or all `chrome.storage.local` data across profiles. A shared extension context cannot directly run content scripts in tabs belonging to another Chromium profile. For extensions that support a browser-provided account handoff, a separate, opt-in broker can hold narrowly scoped authentication material in the browser's protected store and deliver it to each profile's extension instance after identity and permission checks. Extensions that use their own account sync can instead sign in independently; that alone does not make the session single sign-in. The broker needs an explicit extension contract and security review before it can be enabled. Password managers must not have their vault or arbitrary storage copied by the browser.

The initial draft establishes the durable catalog, fan-out/reconciliation API, explicit partial-failure reporting, and idempotent native replays that preserve per-profile enable state. Creating a missing profile instance still needs a reviewed Chromium installer hook, package provenance, and consent binding. The sign-in acceptance criterion needs a supported extension contract and a two-profile authenticated probe. Keep the PR draft while those paths and native compilation are pending.
